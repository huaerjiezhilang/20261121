# 软软的生日小屋

一个在本地运行的温馨卡通 3D 生日寻宝 demo。使用 React、Three.js 和 Vite；家具、植物、小猫、蛋糕均为程序化 3D 模型，无需外部图片或模型服务。

当前版本采用简笔画式 2D 动漫画风：平涂色块、三档明暗与深色轮廓线，保留第一人称自由行走。房间由约 8.5 × 6.8 扩大到 12.5 × 10.8 个场景单位，家具保持原有尺寸，新增阅读桌、立起来的相框和绿植工作台。

## 启动

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的本地地址，通常是 http://127.0.0.1:5173 。本项目需要通过本地服务器打开，不能直接双击 index.html。

```powershell
npm.cmd run build
npm.cmd run preview
```

## GitHub Pages 发布

自动发布配置位于 `.github/workflows/deploy.yml`。首次发布需在目标仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。

将项目源文件、`public/`、锁文件和工作流推送至 `main` 或 `master` 后，Actions 会安装依赖、检查谜题逻辑、构建并发布 `dist/`。无需上传 `node_modules/`、`dist/` 或本地测试截图。发布地址以 Actions 的 `github-pages` 环境输出为准，通常为 `https://<账号>.github.io/<仓库名>/`。

构建使用相对资源路径，兼容 GitHub Pages 的仓库子目录。网站访问者不需要启动本地服务器；探索进度仍单独保存在每台设备的浏览器中。

## 玩法

- 点击「走进小屋」，以人眼高度进入封闭 3D 房间。WASD 行走，鼠标转头；Esc 释放鼠标。
- 走近家具，对准后按 E 或点击浮现的小圆点，互动提示显示在左下角（手机位于方向键上方），解开五道小机关、收集五根生日彩带。物品有距离和遮挡检查。
- 「生日彩带」中可以查看已收集的彩带祝福与尚未找到的彩带线索。五个机关分别需要输入时间密码、给植物浇水、把生日帽戴到靠墙的小猫熙熙头上、把书架第一层和第三层的书拖成从矮到高、在平板上答对两题；错误操作可以重试。
- 门旁有实体灯光开关，走近后点击或按 E，可开关室内灯光。关灯后保留窗外月光，仍能看清家具与通路。
- 后墙上原本就挂着 8 条三角形装饰彩带（沿用旧版彩旗的形状），它们没有数字、也不能移动；中间留出 5 个位置。每解开一道机关，就会有一根编号 1~5 的彩带亮起：1、4、5 号是圆点，2、3 号是横线。收齐五根后走到后墙边，用鼠标或手指按住中间这五根彩带直接左右拖动，让数字从 1 排到 5，中央礼盒才会解锁。
- 中央茶几的礼盒起初被完整罩住；中间五根彩带未集齐并排好前，互动会提示还差什么。排好后再次互动，盒盖抬起、盒身展开淡出，蛋糕渐渐显露，视线缓缓转向蛋糕。
- 揭盒时室内灯光渐暗，窗外切换为月夜，淡蓝色月光与窗格光斑照入房间，家具仍可辨认；蛋糕附近保留摇曳的暖色烛光。旁边的唱片自动播放《祝你生日快乐》八音盒纯音乐，并随音乐旋转；无需提前开启音乐。出场动画期间暂停行走，结束后显示许愿面板。可在许愿和祝福窗口暂停或重新播放。
- 吹灭蜡烛后，室内灯光重新亮起。关闭许愿面板也可以继续在烛光中探索，再到门边开灯。礼盒揭开状态随进度保存，重新探索会把礼盒合上、灯光和音乐重置。
- 生日曲播放一遍后停止，可再次打开蛋糕重播。关闭祝福窗口不会中断音乐；重新探索会停止音乐并重置。刷新页面不会自动发声。
- 点击靠墙的小猫熙熙可以给它戴上生日帽；书架的第一层和第三层的书都能直接用鼠标或手指拖动排序；点击角落的唱片机会翻开一张专辑《一起去看音乐祭》（庸俗救星 VulgarSavior，IP 属地 中国台湾）。右上角可打开本地合成的八音盒音乐。
- 也可按住画面拖动转头，上下方向键前后走，左右方向键转头。手机横屏使用：左侧方向按钮行走、滑动转头、右侧互动按钮；竖屏会显示旋转手机提示并暂停行走，转回横屏后继续当前进度。互动提示不再显示键盘按键 E。
- 弹窗打开、窗口失焦时会停止移动。进度保存在当前浏览器，刷新保留；口袋中可重新探索，回转箭头只重置位置。

## 后续修改位置

- `src/content.js`：收礼人名字、彩带名称、线索、祝福。
- `src/room.js`：3D 房间、家具、灯光、相机和物品交互位置。
- `src/main.jsx`：游戏流程、收藏、许愿和界面。
- `src/style.css`：奶油色与鼠尾草绿视觉、桌面与手机布局。
- `src/audio.js`：本地合成八音盒配乐。
- `src/birthday-score.js`：《祝你生日快乐》主旋律与伴奏音符。
- `src/walking.js`：人物碰撞半径、家具占地和移动碰撞。
- `src/first-person.js`：鼠标、键盘、触屏与第一人称相机控制。
- `src/first-person.css`：全屏场景、探索界面和触屏操作。
- `src/puzzles.js`：谜题条件、答案校验、道具、线索和渐进提示。
- `src/PuzzlePanel.jsx` 与 `src/puzzles.css`：谜题操作界面与彩带样式。
- `src/doodle.css`：简笔画描边与平涂 UI。
- `src/handwriting.css`：本地手写字体、字号与生日音乐控件。
- `src/mobile-landscape.css`：手机横屏布局、横屏许愿面板和旋转手机提示。

界面与房间的手写字体使用「小赖字体 / Xiaolai」，打包在 `public/fonts/xiaolai/` 并按出现的文字分片加载，运行时无需连接字体服务。房间墙上的标牌文字使用系统楷体绘制。生日纯音乐由浏览器合成，没有人声，不需要外部音频服务。

当前人物名字与祝福均为可替换的 demo 内容。场景使用第一人称透视相机，固定眼高 1.85 米，有房间边界与家具碰撞。鼠标锁定不可用时，仍可拖动转头和按键行走。没有跳跃、楼层或多人联机。

解谜版本使用独立的 `birthday-little-room-v2` 浏览器存档，保留旧版本存档，第一次进入从新机关开始。刷新会保留机关状态、已取得的道具与彩带进度；只有「重新探索」会重置本版本进度。

## 本地验证

```powershell
node scripts/check-puzzles.mjs
```

验证彩带与书架谜题的正确/错误答案、道具前置条件、奖励不重复、存档恢复，以及扩大后房间的通路；CI 也会运行它。

另外三个脚本需要在开发服务器（或构建产物）上用本地 Microsoft Edge 运行，截图写入 `test-results/`：`node scripts/check-pages.mjs`（生产构建、字体、弹窗）、`node scripts/check-landscape.mjs`（手机横竖屏与触屏）、`node scripts/check-joystick.mjs`（虚拟摇杆）。其他系统可修改脚本中的浏览器路径。

## 技术要求

使用支持 WebGL 2 的现代浏览器，建议开启硬件加速。安装依赖需联网，安装后运行及游戏内容不依赖外部网络服务。系统减少动态效果设置会关闭装饰动画。
